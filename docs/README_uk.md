# InstallZone - Професійна модульна система інсталяторів (Українська)

> **Високонадійна модульна система інсталяторів для Linux за стандартами JPL, створена на C++17, OpenGL2, Dear ImGui та вбудованому JavaScript.**  
> Оптимізовано для Kubuntu 26.04.1 LTS із KDE Plasma.

---

## 🌟 Ключові особливості

- **Архітектура з двох додатків**:
  1. **InstallZone Studio (`installzone-studio`)**: Інструмент розробника для пакування файлів, визначення залежностей, конфігурації ярликів FreeDesktop та написання скриптів JavaScript. Створює автономний бінарний файл інсталятора `.run`.
  2. **InstallZone Base Runner (`installzone-runner`)**: Автономний майстер встановлення, який зчитує вбудовані ресурси, перевіряє залежності, за потреби запитує підвищення прав через Polkit/sudo, розпаковує компоненти зі збереженням прав доступу, виконує скрипти конфігурації та створює деінсталятор.
- **Вбудований рушій JavaScript**: Повнофункціональний рівень ECMAScript (на базі Duktape) для створення папок `~/.config`, налаштування утиліт (наприклад, шпаргалок `navi`), конфігурації середовища та виконання системних операцій.
- **Стандарти надійності JPL**: Дотримання ключових правил NASA/JPL (обмежені цикли, фіксовані розміри буферів пам'яті, контроль повернення функцій, перевірки інваріантів, відсутність нескінченних циклів).
- **Багатопотокова робота без блокування інтерфейсу**: Потік інтерфейсу (UI) та робочий потік логіки повністю розділені. Графічний інтерфейс працює на 60 FPS без затримок під час важких дискових операцій, а ImGui ізольовано виключно в головному потоці для уникнення втрати контексту.
- **Повна локалізація «з коробки»**: Вбудована підтримка 12 мов:
  Українська, Англійська, Японська, Китайська, Іспанська, Французька, Німецька, Португальська, Італійська, Польська, Корейська та Російська.
- **Чиста структура каталогу**: У кореневій теці розміщені тільки `install.sh`, `reinstall.sh`, `uninstall.sh` та файли Git.

## 🚀 Швидкий старт

### Встановлення

```bash
# Збірка та встановлення в ~/.local (або /usr/local з правами root)
./install.sh
```

### Перевстановлення та видалення

```bash
# Чисте перевстановлення
./reinstall.sh

# Повне видалення з системи
./uninstall.sh
```

### Запуск

- З головного меню KDE Plasma: знайдіть **InstallZone Studio**
- Через термінал:
  ```bash
  installzone-studio
  ```
