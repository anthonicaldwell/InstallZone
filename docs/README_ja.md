# InstallZone - モジュール式スクリプタブルインストーラーシステム (日本語)

> **C++17、OpenGL2、Dear ImGui、組み込み JavaScript を採用した、JPL安全基準に基づく Linux 向け高信頼インストーラーシステム。**  
> KDE Plasma 搭載の Kubuntu 26.04.1 LTS を主対象として最適化されています。

---

## 🌟 主な特長

- **2つのアプリケーションで構成**:
  1. **InstallZone Studio (`installzone-studio`)**: アセットのパッケージング、依存関係の定義、FreeDesktop デスクトップ項目の設定、JavaScript によるセットアップスクリプトを統合管理し、単一のスタンドアロン `.run` バイナリを出力。
  2. **InstallZone Base Runner (`installzone-runner`)**: パックされた自己展開型インストーラーウィザード。内蔵ペイロードを直接読み取り、依存関係チェック、Polkit による管理者権限の取得、権限を維持したファイル展開、JavaScript スクリプトの実行、アンインストーラーの生成を実施。
- **組み込み JavaScript エンジン**: Duktape を活用し、`~/.config` 配下のフォルダ自動作成や `navi` の設定ファイル配備、環境変数の設定などを安全に自動化。
- **JPL（NASA/ジェット推進研究所）コーディング規約に準拠**: 安定性とセキュリティのため、ループ回数上限の設定、動的メモリの境界チェック、明示的なエラー戻り値検証、ゼロ再帰を徹底。
- **UIとロジックの完全スレッド分離**: ImGui のコンテキスト消失（Context Loss）を防ぐため、すべての描画処理をメインスレッドに制限し、バックグラウンドワーカーとはスレッドセーフなブリッジで非同期通信。高負荷な展開中でも 60 FPS で滑らかに動作。
- **12言語のネイティブ多言語対応**:
  日本語、英語、ウクライナ語、中国語（簡体字）、スペイン語、フランス語、ドイツ語、ポルトガル語、イタリア語、ポーランド語、韓国語、ロシア語を標準搭載。

## 🚀 クイックスタート

### インストール方法

```bash
# ビルドおよび ~/.local (または root 時は /usr/local) へのインストール
./install.sh
```

### 再インストールとアンインストール

```bash
# 再ビルドおよび再インストール
./reinstall.sh

# 完全アンインストール
./uninstall.sh
```

### 起動方法

- アプリケーションメニューより: **InstallZone Studio**
- ターミナルから:
  ```bash
  installzone-studio
  ```
