# Довідник зі створення скриптів InstallZone (Українська)

InstallZone містить вбудований рушій JavaScript (на базі Duktape) для автоматизації складних операцій встановлення, конфігурації системи, налаштування оточення та ініціалізації залежностей (таких як створення папок `~/.config` або налаштування утиліт на зразок `navi`).

---

## 1. Життєвий цикл виконання та хуки (Hooks)

InstallZone надає чотири хуки для виконання коду JavaScript:

1. **Хук перед встановленням (`pre_install_js`)**:
   - Виконується **до** розпакування файлів у цільову теку.
   - Застосування: перевірка умов, зупинка фонових служб/демонів, створення резервних копій конфігурацій.

2. **Хук після встановлення (`post_install_js`)**:
   - Виконується **після** розпакування компонентів та додавання ярликів у меню додатків.
   - Застосування: створення каталогів конфігурації користувача (наприклад, `~/.config/<додаток>`), налаштування інтеграцій (шпаргалки `navi`, автодоповнення для командної оболонки), встановлення змінних середовища, створення символьних посилань.

3. **Хук перед видаленням (`pre_uninstall_js`)**:
   - Виконується **до** видалення файлів під час деінсталяції.
   - Застосування: зупинка сервісів, скасування реєстрації служб.

4. **Хук після видалення (`post_uninstall_js`)**:
   - Виконується **після** видалення всіх файлів, значків та ярликів.
   - Застосування: очищення кешу користувача або запит на збереження налаштувань.

---

## 2. Глобальний об'єкт: `iz`

Контекст виконання автоматично надає глобальний об'єкт `iz`.

### Властивості

| Властивість | Тип | Опис |
| :--- | :--- | :--- |
| `iz.app_name` | `string` | Відображувана назва додатку. |
| `iz.version` | `string` | Рядок версії (наприклад, `"1.0.0"`). |
| `iz.install_dir` | `string` | Абсолютний шлях до теки встановлення (наприклад, `"/opt/myapp"`). |
| `iz.home_dir` | `string` | Домашня тека реального користувача (наприклад, `"/home/ім'я"`). Коректно визначається навіть при запуску через `sudo` або `pkexec`. |
| `iz.config_dir` | `string` | Тека конфігурацій користувача (`~/.config`). |
| `iz.is_uninstall` | `boolean` | `true`, якщо виконується видалення додатку; `false` під час встановлення. |

---

### Методи

#### `iz.log(повідомлення)`
Виводить текстове повідомлення в консоль та в журнал інсталятора у реальному часі.
```javascript
iz.log("Початок налаштування конфігурації додатку...");
```

#### `iz.mkdir(шлях)`
Рекурсивно створює каталоги (`mkdir -p`). Символ тильди (`~/`) автоматично замінюється на домашню теку користувача. При виконанні з правами root права власності на створені файли передаються реальному користувачеві.
```javascript
var cfgDir = iz.config_dir + "/myapp";
iz.mkdir(cfgDir);
```

#### `iz.write_file(шлях, вміст)`
Записує текстові дані у вказаний файл. За потреби автоматично створює всі батьківські теки.
```javascript
var configFile = iz.config_dir + "/myapp/settings.json";
iz.write_file(configFile, JSON.stringify({ theme: "dark", telemetry: false }, null, 2));
```

#### `iz.read_file(шлях)`
Зчитує та повертає вміст текстового файлу у вигляді рядка. Повертає `null`, якщо файл не вдалося відкрити.
```javascript
var data = iz.read_file(iz.config_dir + "/myapp/settings.json");
```

#### `iz.file_exists(шлях)`
Повертає `true`, якщо файл або тека існує; інакше `false`.

#### `iz.remove(шлях)`
Видаляє файл або порожню теку за вказаним шляхом.

#### `iz.copy(звідки, куди)`
Копіює файл з одного місця в інше.

#### `iz.exec(команда)`
Виконує команду в командній оболонці Linux та повертає об'єкт із кодом виходу (`exit_code`) та стандартним виводом (`stdout`).
```javascript
var res = iz.exec("which navi");
if (res.exit_code === 0) {
    iz.log("Знайдено утиліту navi: " + res.stdout.trim());
}
```

## 3. Практичний приклад: Налаштування конфігурації для Navi

Якщо ваш додаток інтегрується з `navi` або надає власні шпаргалки, їх можна сконфігурувати у `post_install_js`:

```javascript
iz.log("Налаштування інтеграції з Navi для " + iz.app_name + "...");

var naviCheatsDir = iz.home_dir + "/.config/navi/cheats";
iz.mkdir(naviCheatsDir);

var cheatContent = 
    "% " + iz.app_name + "\n" +
    "# Запустити " + iz.app_name + " з детальним виводом\n" +
    iz.app_name.toLowerCase() + " --verbose\n\n" +
    "# Скинути стан конфігурації\n" +
    iz.app_name.toLowerCase() + " --reset-config\n";

iz.write_file(naviCheatsDir + "/" + iz.app_name.toLowerCase() + ".cheat", cheatContent);
iz.log("Інтеграцію з Navi успішно налаштовано!");
```
